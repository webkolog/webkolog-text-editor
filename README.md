**Webkolog Text Editor** is a comprehensive, lightweight, and user-friendly tool designed for anyone working with text-based files. It offers the ability to seamlessly open and edit a wide range of formats, from simple `.txt` files to source code in various programming languages. Built with a C# architecture using `.NET Framework 4.5`, it enhances the daily editing experience through a tabbed interface, advanced tab management, data loss prevention mechanisms, and robust search-and-replace functionalities. With built-in multi-language interface support, it provides a comfortable and localized workspace for users worldwide.

## Features

* 🚀 **Easy File Opening:** Quickly open files by dragging and dropping them directly into the program window. It automatically prevents the same file from being opened multiple times to maintain a clean workspace.
* 🌍 **Multi-Language Support:** Easily switch between 9 different interface language options on the fly.
* 🗂️ **Tabbed Working Environment:** Work on multiple files simultaneously with multi-tab support, allowing for smooth transitions between documents.
* 🛠️ **Advanced Tab Management:** Conveniently organize your workspace by closing tabs to the right or left, closing all tabs with a single command, or closing all tabs except the currently active one.
* ⚠️ **Data Loss Prevention:** Detects unsaved changes instantly and warns you before closing, preventing accidental data loss. Modified states are clearly marked in the tab headers.
* 🖨️ **Printing Capability:** Easily print out the files and code snippets you have edited directly from the application.
* 📂 **Practical File Utilities:** Copy the exact file path or filename with one click, or immediately open the file's container directory. Includes a shortcut to quickly insert the current timestamp/date.
* 🔒 **Read-Only Mode:** Open sensitive files in read-only mode whenever necessary to prevent accidental edits or modifications.
* ✍️ **Customizable Interface:** Personalize the font type and text size according to your preferences for an optimized reading and writing experience.
* 📊 **Instant Information:** Displays the current line and column numbers in real-time within the status bar, providing precise navigation during source code editing.
* 🔍 **Quick Search & Replace:** Quickly find and replace words, phrases, or code syntax across your document.

## Installation & Setup

1. Clone or download the repository to your local machine:
```bash
git clone https://github.com/webkolog/webkolog-text-editor.git
```

3. Open the project solution file in Visual Studio.
4. Restore any missing dependencies, build the solution using the `.NET Framework 4.5` target, and run the executable.

## Usage Overview

Using Webkolog Text Editor is very straightforward:

* **Opening Files:** Drag and drop any text or code file onto the main window, or use the `File > Open` menu.
* **Managing Multi-Files:** Each new file populates a new tab. Right-click the tab headers to access advanced tab management features.
* **Searching text:** Use the top menu controls to access the find and replace fields.
* **Saving:** Click the `Save` button or use standard shortcuts. If you try to exit with unsaved modifications, the program will prompt you automatically.
